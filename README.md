# Hello PHP

A tiny PHP hello world project.

## Structure

```
hello-php/
├── index.php        # Entry point (HTML + greeting)
├── src/Greeter.php  # Greeter class
└── README.md
```

## Run it

Requires PHP 7.4+.

```bash
cd hello-php
php -S localhost:8000
```

Then open <http://localhost:8000> or <http://localhost:8000/?name=Asha>.
